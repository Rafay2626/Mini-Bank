# 🏦 Mini Bank

A simple banking website built with Python, Flask, HTML, and CSS. It includes a login page, a banking menu, and a money transfer option.

## ✨ Features

- Login with name and password
- Banking menu
- Money transfer page
- Simple and beginner-friendly interface
- Built with Python and Flask

## 🛠️ Requirements

- Python 3
- pip
- Visual Studio Code (recommended)
- A web browser

## 🐍 1. Install Python

1. Visit https://www.python.org/downloads/
2. Download the latest stable Python 3 version.
3. Run the installer.
4. On Windows, check **Add Python to PATH**.
5. Complete the installation.

Verify Python in your terminal:

```powershell
python --version
```

Check pip:

```powershell
python -m pip --version
```

## 📥 2. Download the Project

Clone the repository:

```powershell
git clone https://github.com/Rafay2626/Mini-Bank.git
```

Open the project folder:

```powershell
cd Mini-Bank
```

Alternatively, click **Code → Download ZIP** on GitHub and extract the downloaded folder.

## 🧪 3. Create a Virtual Environment

```powershell
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, run this command in the same terminal:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Then activate the environment again.

## 📦 4. Install Flask

```powershell
python -m pip install Flask
```

## ▶️ 5. Run the Project

Make sure the virtual environment is activated, then run:

```powershell
python app.py
```

Open the local URL shown in the terminal. If the app uses Flask's default port, visit:

http://127.0.0.1:5000
